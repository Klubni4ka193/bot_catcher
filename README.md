# Bot Catcher

**Bot Catcher** — программный комплекс для анализа подписчиков публичных каналов и обнаружения автоматизированных аккаунтов в социальных медиа.

Практическая реализация проекта выполнена на примере мессенджера **Telegram**.  
Система собирает профильные данные подписчиков публичного канала, извлекает признаки аккаунтов, рассчитывает интегральную оценку «ботоподобности» и формирует отчёт с результатами классификации.

---

## О проекте

Проект разработан в рамках выпускной квалификационной работы бакалавра на тему:

> **«Программный комплекс для анализа подписчиков и обнаружения ботов в социальных медиа»**

Основная задача проекта — автоматизировать анализ аудитории публичного канала и выявлять подозрительные аккаунты, которые могут использоваться для накрутки подписчиков.

Система не принимает окончательное решение за администратора канала, а предоставляет интерпретируемую оценку и список признаков, по которым аккаунт был признан подозрительным.

## Возможности

- сбор профильных данных подписчиков публичного Telegram-канала;

- расчёт скорингового балла для каждого аккаунта;
- классификация аккаунтов на ботов и реальных пользователей;

- построение диаграммы распределения аккаунтов;
- вывод краткой статистики по результатам анализа.

## Используемый подход

Для каждого подписчика рассчитывается набор признаков, отражающих типичные аномалии автоматизированных аккаунтов:

- отсутствие фотографии профиля;
- подозрительный или случайный `username`;
- пустая биография;
- отсутствие фамилии;
- совпадение `username` и имени;
- скрытый статус активности;
- односимвольное или шаблонное имя;
- отсутствие публичного имени пользователя.

Каждому признаку назначается вес. Если признак срабатывает, его вес добавляется к итоговому баллу аккаунта.

Итоговая оценка рассчитывается по формуле:

```text
S = Σ(wᵢ · xᵢ)
```

где:

- `S` — итоговый скоринговый балл аккаунта;
- `wᵢ` — вес i-го признака;
- `xᵢ` — значение i-го признака:
  - `1`, если признак активен;
  - `0`, если признак не активен.

Если итоговый балл `S` больше или равен заданному порогу `T`, аккаунт классифицируется как бот:

```text
если S ≥ T → бот
если S < T → реальный пользователь
```

Склонируйте репозиторий:

```bash

cd bot_catcher
```

Создайте виртуальное окружение:

```bash

```

```bash

```


## Конфигурация

Основные параметры работы программы задаются в файле `config.yaml`.

Пример конфигурации:

```yaml
threshold: 80

weights:
  no_photo: 15
  random_username: 20
  empty_bio: 10
  missing_last_name: 10
  username_matches_firstname: 10
  hidden_status: 15
  default_first_name: 20
  no_username: 5

limits:
  max_subscribers: 10000
  batch_size: 200

output:
  csv_file: "report.csv"
  chart_file: "bot_distribution.png"
```

### Описание параметров

| Параметр | Назначение |
|---|---|
| `threshold` | Порог классификации аккаунта как бота |
| `weights` | Веса признаков скоринговой модели |
| `max_subscribers` | Максимальное количество подписчиков для анализа |
| `batch_size` | Размер пакета при сборе данных |
| `csv_file` | Имя CSV-файла с результатами |
| `chart_file` | Имя файла с диаграммой |

## Пример логики классификации

Если у аккаунта сработали следующие признаки:

- отсутствует фотография профиля;
- `username` выглядит случайным;
- скрыт статус активности;
- пустая биография;
- отсутствует фамилия;
- имя состоит из одного символа,

то итоговый балл может превысить порог классификации, и аккаунт будет отнесён к ботам.

При этом решение остаётся интерпретируемым: в отчёте отображаются конкретные причины, из-за которых аккаунт получил высокий балл.

## Ограничения

Система имеет ряд ограничений:

- анализируются только статические данные профиля;
- не учитывается поведение пользователей внутри канала;
- не анализируются просмотры, реакции, репосты и сообщения;
- качество классификации зависит от выбранных весов и порога;
- Telegram API может ограничивать скорость сбора данных;
- для крупных каналов может анализироваться только часть аудитории.

Результаты работы системы следует рассматривать как инструмент предварительного анализа аудитории, а не как абсолютно точное решение.
